iOS 27 无线安装 · 无需数据线 · 无需电脑
好消息：你的 iOS 27 支持「设备自配对」，整个安装过程可以在 iPhone 上完成， 不用数据线、不用电脑。下面的 App 都从 App Store 官方下载。

1装三个官方 App

⌘ rootshell
本地终端 · App Store 获取 › ▤ Open Minis
运行安装脚本 · App Store 获取 › ⇄ LocalDevVPN
本地回环隧道 · App Store 获取 ›

三个都是免费 App Store 应用，无需账号。

2装 SideInstaller

打开 sideinstaller.net， 按页面上的 1→2→3 步操作：

  • 在 rootshell 里打开 Local Shell（右上角 Open），逐行执行：
curl -fsSLO https://raw.githubusercontent.com/FrizzleM/siboot/main/rootshell/bin/siboot-pair.wasm ifconfig en0 > ifconfig.txt ./siboot-pair.wasm
  • rootshell 会显示一个配对码。打开 设置 › 隐私与安全性 › 开发者模式，滚到底部点 Pair with siboot， 输入密码和那个配对码。
  • 回到 rootshell，保持它运行。
  • 连接 LocalDevVPN，打开 Open Minis，右上角控制台图标 → Shell Terminal，执行：
wget -qO- https://raw.githubusercontent.com/FrizzleM/siboot/main/minis/install.sh | sh
  • 输入 rootshell 显示的传输码（仅首次），再输入你的 Apple ID 邮箱、密码和验证码。
  • 首次完成后，去 设置 › 通用 › VPN 与设备管理 信任你的 Apple 账号。
关于 Apple ID：它只在本机用于签名，不会上传到任何服务器。 SideInstaller 开源可审计。建议用小号。

3装经典书房

SideInstaller 装好后：

  • 保持 LocalDevVPN 已连接，打开 SideInstaller
  • 登录 Apple ID → 点 Install SideStore（或 SideStore + LiveContainer）
  • SideStore 装好后，Safari 打开下面这个链接即可一键装经典书房：
一键安装经典书房 点我 → Safari 会交给 SideInstaller 处理

页面会显示 IPA 的下载地址，并提供按钮把它交给 SideInstaller。 若 Safari 没自动跳转，就点页面上的按钮。

4首次打开

  • 打开「经典书房」，如提示不受信任的开发者→ 设置 › 通用 › VPN 与设备管理 › 点你的 Apple ID → 信任
  • 如提示需要开发者模式→ 设置 › 隐私与安全性 › 开发者模式 → 开启 → 重启手机

关于 7 天有效期

免费 Apple ID 签名的 App 有效期 7 天。到期前用 SideStore 打开 My Apps → Refresh All 重签即可，无需电脑、无需数据线。

建议每 5～6 天手动刷新一次，或在 SideStore 设置里开启后台自动刷新。 你的阅读进度存在本机，重签不会丢。

安全提示：只从 sideinstaller.net 和 官方 GitHub 获取 SideInstaller。 注意 sideinstaller.com 是假站点，可能携带木马。 这类工具开放源码，任何人都会做同样的图标和名字分发恶意版本。
