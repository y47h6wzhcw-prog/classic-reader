iOS 27 无线安装 · 免数据线 · 免电脑 · 国区可用
好消息：iOS 27 支持「设备自配对」，整个安装过程在 iPhone 上完成， 不用数据线、不用电脑。下面用的 AirSign 走 TestFlight 官方分发， 国区 App Store 可以直接下载 TestFlight，不用切区、不用小号。

1装 AirSign

用 iPhone 的 Safari 打开这个链接，按提示安装：

打开 TestFlight 邀请链接 testflight.apple.com/join/uvCeQG8t
  • 没装 TestFlight 会自动跳到 App Store 让你装（国区有）
  • 点 Accept / Install 接受邀请，等下载完成
  • 首次打开如果提示要打开开发者模式，按提示走（见第 2 步）

官方文档：tarplay.com/airsign/guide （Safari 打开后可用菜单「翻译成简体中文」）

2开开发者模式

  • 设置 › 隐私与安全性 › 开发者模式 → 打开
  • 手机会重启，重启后回到这个页面点「启用」确认

这一步是 Apple 对所有侧载 App 的强制要求，不开无法签名安装。

3在 AirSign 里登录并配对

3
检测设备 UDID 首页 UDID 旁点「检测 / Detect」→ 选「Auto-Detect via Safari Profile」→ 允许 → 回到「设置」点「已下载描述文件」→ 安装。这个临时描述文件会自动移除。
3
登录 Apple ID 「2. APPLE ACCOUNT」区 → 点「Sign In with Apple ID」→ 填邮箱、密码和 6 位验证码。
3
无线配对（仅 iOS 27+，免电脑的关键） 在「APPLE ACCOUNT」区点 Wireless Pair (No PC) → AirSign 会显示一个 6 位配对码 → 打开 设置 › 隐私与安全性 › 开发者模式，滚到底部点 Pair with AirSign，输入锁屏密码和那 6 位码。
2FA 收不到短信？在验证码输入框里有「Send Code via SMS」和 「Call Me with Code」按钮，语音电话通常更可靠。 另需在 设置 › 隐私与安全性 › 本地网络 里确认 AirSign 已打开。

4签名并安装

在 AirSign 首页「1. SIGN & INSTALL .IPA」区：

  • 点 🌐 Sign & Install from URL（从链接获取），粘贴下面的地址：
https://github.com/y47h6wzhcw-prog/classic-reader/releases/download/v1.0.0/reader-1-unsigned.ipa
  • 点 签名，等进度条走完
  • 弹出「tarplay.com 想要安装…」→ 点 安装
  • 回到桌面，「经典书房」图标就出来了

也可以先用 Safari 下载 IPA 到「文件」App，再点 📦 Pick & Sign .ipa from Files 选中它。

5首次打开

  • 打开「经典书房」，若提示不受信任的开发者 → 设置 › 通用 › VPN 与设备管理 → 点你的 Apple ID → 信任
  • 若提示需要开发者模式 → 设置 › 隐私与安全性 › 开发者模式 → 开 → 重启

关于 7 天有效期

免费 Apple ID 签名的 App 有效期 7 天。到期前打开 AirSign，保持同一 Apple ID 登录， 在 INSTALLED APPS 列表里找到「经典书房」点 Re-sign（或重新选同一个 IPA 签名）， iOS 会原地覆盖升级，阅读进度、书签都保留。

建议每 5～6 天刷一次。免费账号最多同时装 3 个侧载 App —— 只装这一个不受影响。

隐私说明

AirSign 的 Apple ID 登录是手机直连 gsa.apple.com（Apple 官方服务器）， 私钥和证书全程留在本机，不经过 AirSign 的服务器。它只在两处联系自己的域名： UDID 一次性登记、以及你主动点「Send Diagnostics」时。

请注意：AirSign 是较新的第三方工具（v1.0，早期阶段），建议先用一个 无所谓的小 IPA 试一遍完整流程，确认没问题再装正式应用。 不要用主力 Apple ID，用小号。IPA 请只从本页或 GitHub 仓库获取。

备选方案：SideInstaller（需美区/港区 Apple ID）

如果你想用 SideStore 生态（可后台自动续签），另一条路是 SideInstaller， 但它依赖 rootshell 和 LocalDevVPN 两个 App—— 这两个国区 App Store 没有（实测），需要美区或港区账号。 AirSign 不需要切区，是国区最省事的路。

⚠️ 只从 sideinstaller.net 和官方 GitHub 获取 SideInstaller， sideinstaller.com 是假站点。
